# VN-Digitize AI Engine, combined demo (test build)

One Streamlit app with both clusters of the project, on the free Streamlit Community Cloud:

- Module 1: camera photo -> crop, straighten, blank-page flag, QR codes.
- Modules 2 + 3: scanned land-record PDF -> OCR -> structured records.

It copies the project code unchanged and adds only `app.py` and `.streamlit/config.toml`.
Do not upload photos or documents with personal data. Nothing is stored.

Use Python 3.11 (Advanced settings when deploying). Main file: `app.py`.
